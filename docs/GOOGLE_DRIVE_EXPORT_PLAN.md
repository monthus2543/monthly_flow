# แผนส่งออก Excel ไป Google Drive

สถานะ: พักแผน Google Drive — ตามคำขอล่าสุด ปลายทางปัจจุบันเป็นบันทึกในอุปกรณ์หรือส่งอีเมลของบัญชี Login ดู [ขั้นตอนตั้งค่าอีเมล](EMAIL_EXPORT_SETUP.md) โค้ดบริการ Drive เดิมยังคงไว้แต่ไม่มีตัวเลือกในหน้าส่งออก

แบบอ้างอิง: [Monthly Flow / 05 · Guide / Development plan / Excel](https://design.penpot.app/#/workspace?team-id=45145cff-4092-8110-8008-ac2045ef414d&file-id=19c47d73-0a5d-8067-8008-bab751d38f00&page-id=14936641-d32a-801f-8008-babe60a5ca43&layout=layers)

## ขั้นตอนใช้งาน

เลือกปีหรือทุกปี → เลือกบันทึกลงเครื่องหรือ Google Drive → ขอสิทธิ์ Drive ครั้งแรก → สร้างไฟล์ .xlsx → อัปโหลด → แสดงผลสำเร็จและปุ่มเปิดไฟล์

- ไฟล์เดียวแยก Sheet ละปี ใช้ข้อมูลสรุปชุดเดียวกับหน้ารายงานเพื่อให้ยอดตรงกัน
- สร้างโฟลเดอร์ `Monthly Flow/Reports` ใน Drive ของบัญชี Google ที่เลือก
- ชื่อไฟล์ระบุช่วงปีและวันเวลา เก็บการส่งออกแต่ละรอบโดยไม่เขียนทับอัตโนมัติ
- ผู้ใช้ที่ไม่ได้เชื่อม Google Drive ยังบันทึกลงเครื่องได้

## ลำดับพัฒนา

1. ทำ Google Login และแสดงบัญชีที่ใช้ส่งออก รองรับออกจากระบบและเปลี่ยนบัญชี
2. ทำตัวสร้างรายงาน .xlsx พร้อมสรุป 12 เดือน รายการ และกราฟ แยก Sheet ตามปี ทดลองรูปแบบกราฟก่อนเลือกไลบรารี
3. ตั้งค่า Google Cloud project, Drive API, OAuth client และหน้าขอความยินยอมตามแพลตฟอร์ม
4. ขอสิทธิ์ `drive.file` เมื่อเลือกส่งออกไป Drive แยกจากขั้นตอน Login ใช้ access token ที่ได้รับสิทธิ์ Drive สำหรับอัปโหลด
5. ทำบริการอัปโหลด สร้างหรือค้นหาโฟลเดอร์ที่แอปมีสิทธิ์เข้าถึง จัดเก็บ folder ID/file ID โดยแยกตามบัญชี และคืนลิงก์เปิดไฟล์
6. ใช้ Riverpod จัดการสถานะสร้างไฟล์ / อัปโหลด / สำเร็จ / ผิดพลาด พร้อม Progress ที่สะท้อนงานจริง
7. เพิ่มบันทึกลงเครื่องและลองอัปโหลดใหม่ โดยเก็บไฟล์เดิมเมื่อส่งล้มเหลว ตรวจผลการส่งที่ไม่ชัดเจนด้วย file ID ก่อนสร้างไฟล์ซ้ำ

## เงื่อนไขจบงาน

- เปิดไฟล์ .xlsx ได้ จำนวนเงินเป็นตัวเลข วันที่เป็นวันที่ ภาษาไทยไม่เสีย และยอดตรงหน้ารายงาน
- รองรับเลือกปีเดียว หลายปี ทุกปี และปีที่ไม่มีข้อมูล
- ขอสิทธิ์ครั้งแรกได้ รองรับยกเลิก ไม่อนุญาต สิทธิ์หมดอายุ และถอนสิทธิ์
- ไม่มีอินเทอร์เน็ตยังสร้างและบันทึกลงเครื่องได้
- เน็ตหลุดหรือ Drive เต็มแสดงเหตุผลและให้ลองใหม่ได้ การลองใหม่ไม่สร้างไฟล์ซ้ำโดยไม่จำเป็น
- เปิดไฟล์ใน Drive ได้หลังส่งสำเร็จ และเปลี่ยนบัญชีแล้วข้อมูลปลายทางไม่ปะปน
- ทดสอบ Light/Dark จอเล็ก และรายการจำนวนมาก

การส่งออก Excel เป็นรายงาน แยกจากการสำรอง JSON และการซิงก์ข้อมูลข้ามเครื่อง งานนี้ยังไม่เพิ่มระบบซิงก์หรืออัปโหลดเบื้องหลังอัตโนมัติ
