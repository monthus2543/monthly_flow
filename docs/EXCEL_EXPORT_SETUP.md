# ส่งออก Excel

อัปเดตปลายทาง: ผู้ใช้ที่ไม่ Login บันทึกในอุปกรณ์ ส่วนผู้ใช้ที่ Login เลือกบันทึกในอุปกรณ์
หรือส่งไฟล์แนบอัตโนมัติไปอีเมลของบัญชีได้ ดู [การตั้งค่าส่งอีเมล](EMAIL_EXPORT_SETUP.md)
ตัวเลือก Google Drive ในหน้าส่งออกถูกแทนด้วยอีเมลแล้ว

เข้า **ตั้งค่า → ข้อมูลของฉัน → ส่งออก Excel**

เลือกปีเดียว หลายปี หรือทุกปี กรองบัญชี/กระเป๋าเงินและหมวดหมู่
เปิด/ปิดกราฟได้ ก่อนสร้างไฟล์สามารถดูตัวอย่างข้อมูลจริงได้
ชื่อชีตและตัวเลือกปีใช้ ค.ศ. ทั้งภาษาไทยและภาษาอังกฤษ

ไฟล์หนึ่งประกอบด้วยชีตภาพรวมและชีตแยกปี แต่ละปีมีสรุป 12 เดือน
สรุปรายจ่ายตามหมวดหมู่และรายการทั้งหมด กราฟเป็นกราฟ Excel ที่แก้ต่อได้
รายรับ/รายจ่ายนับจากรายการ ไม่รวมยอดเปิดบัญชีเป็นรายรับ และไม่นำสุทธิไปนับซ้ำในกราฟสัดส่วน
ตัวอย่างหน้าจอแสดงรายการ 30 รายการแรก ส่วนไฟล์มีรายการครบ
จำนวนเงินเป็นตัวเลข THB วันที่เป็นวันที่จริง ชื่อรายการ/หมายเหตุเป็นข้อความ
ไม่ส่งออกไฟล์รูปใบเสร็จ รูปโปรไฟล์ PIN หรือข้อมูลสิทธิ์ Google

## บันทึกในอุปกรณ์

ใช้งานได้โดยไม่เชื่อมต่อ Google และไม่ต้องมีอินเทอร์เน็ต
กดสร้างไฟล์ แล้วเลือกบันทึกลงอุปกรณ์หรือแชร์ไฟล์
หากยกเลิกเลือกตำแหน่งบันทึก แอปไม่แจ้งว่าบันทึกสำเร็จ

## แผน Google Drive เดิม (พักไว้ ไม่ใช่ปลายทางปัจจุบัน)

ใช้ Google Cloud project เดียวกับ Firebase `monthly-flow-75287`

1. เปิด [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com?project=monthly-flow-75287) แล้วกด Enable
2. เข้า Google Auth Platform → Branding ตั้งชื่อแอป อีเมลสนับสนุน และข้อมูลติดต่อ
3. เข้า Audience หากเป็น External และยังอยู่ Testing ให้เพิ่มอีเมลบัญชีทดสอบใน Test users
4. เข้า Data Access เพิ่ม scope `https://www.googleapis.com/auth/drive.file`
5. ตรวจ OAuth clients ของ Android ให้ package name และ SHA-1 ตรงกับชุดที่ใช้ Google Login
   ใช้ Web client สำหรับ server client ID ตามการตั้งค่า Google Login เดิม
   iOS ต้องมี OAuth client และ URL scheme ของแอปตามเอกสาร Login เดิม
6. รันแอปใหม่หลังเพิ่ม dependency แล้วเข้าสู่ระบบ Google เลือกปลายทาง Google Drive
7. เลือกบัญชีเดียวกับที่เข้าสู่ระบบและอนุญาตสิทธิ์ Drive
8. ตรวจโฟลเดอร์ `Monthly Flow/Reports` และกดเปิดไฟล์หลังส่งสำเร็จ

แอปขอสิทธิ์เฉพาะไฟล์ที่สร้าง/เข้าถึงผ่านแอป ไม่ขอสิทธิ์อ่าน Drive ทั้งหมด
สิทธิ์ Drive แยกจาก Firebase Login และไม่ต้องใช้ Firebase Storage สำหรับไฟล์รายงาน
ไม่มี service account หรือ client secret ฝังในแอป และไม่บันทึก access token ลงฐานข้อมูล

## เมื่อส่งไม่สำเร็จ

ไฟล์และ file ID เดิมยังอยู่ในหน้าส่งออกให้ลองส่งซ้ำหรือบันทึกลงอุปกรณ์
แอปตรวจ file ID ก่อนส่งใหม่เพื่อกู้คืนกรณีส่งสำเร็จแต่ไม่ได้รับคำตอบ
อัปโหลดแบบ resumable เป็นชิ้นละ 256 KiB และความคืบหน้ามาจากส่วนที่ Drive ตอบรับ
หากเซสชันส่งไม่สำเร็จ การลองใหม่ส่งไฟล์เดิมตั้งแต่ต้นด้วย ID เดิม
การเปลี่ยนบัญชีล้างรายงานที่ค้างจากหน้าจอและหยุดขั้นตอนส่งถัดไป
ไฟล์ที่ส่งสำเร็จแล้วไม่ถูกลบเมื่อออกจากระบบ

ขณะนี้ไฟล์ค้างและสถานะลองใหม่เก็บระหว่างเปิดหน้าส่งออกเท่านั้น
หากต้องการเก็บไว้หลังปิดแอป ให้บันทึกไฟล์ลงอุปกรณ์ก่อนออกจากหน้าจอ

## ผลตรวจและขอบเขต

- ทดสอบเลือกปี/กรองข้อมูล ปีไม่มีรายการ วันที่อธิกสุรทิน ภาษาไทย และรายการ 2,000 แถว
- เปิดไฟล์ด้วยตัวอ่าน Excel อิสระได้ วันที่และจำนวนเงินถูกชนิด กราฟอยู่ครบ
- ทดสอบหน้าจอภาษาไทยขนาด 320 × 640 และข้อความขยาย 1.3 เท่าทั้ง Light/Dark
- ทดสอบบริการ Drive ด้วย HTTP จำลอง: โฟลเดอร์ ไฟล์ ID เดิม การส่งเป็นชิ้น สิทธิ์หมดอายุ และพื้นที่เต็ม
- ยังไม่ได้ทดสอบส่งไฟล์กับบัญชี Google จริงหรือ native save/share บนเครื่องจริง
  ต้องตั้งค่า Drive API และตรวจบน Emulator/มือถือก่อนยืนยันผลจริง
